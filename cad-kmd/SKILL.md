# Скилл: КМД-чертежи в DXF

## Что делать перед любым КМД-чертежом

1. Прочитай profiles.py — реальные размеры профилей по ГОСТ
2. Прочитай drawing_engine.py — используй класс DXFDrawing
3. Все размеры в мм, масштаб 1:1
4. Формат DXF R12 — открывается в любом CAD

## Обязательные элементы КМД-листа

1. Рамка листа (внешняя 1.0мм + внутренняя 0.4мм)
2. Штамп (правый нижний угол, по ГОСТ 2.104)
3. Минимум один вид с масштабом
4. Сечения (минимум А-А поперечное)
5. Спецификация металла в таблице
6. Таблица сварных швов
7. Технические требования (минимум 8 пунктов)

## Стандартный блок технических требований

1. Марка стали — С245 ГОСТ 27772-88
2. Сварка п/а ГОСТ 14771-76, проволока Св-08Г2С ГОСТ 2246-70*
3. Минимальный катет шва по табл.38 СП 16.13330.2017
4. Изготовление по ГОСТ 23118-2019
5. АКЗ: горячее цинкование 85мкм + покраска RAL7011 глянец
6. Очистка поверхности по ГОСТ 9.402-2004 до степени St3
7. Допуски: до 1000мм — ±2мм, до 2500мм — ±4мм
8. Контроль швов: ВИК 100%, УЗК 5%
9. Отверстия сверлить по месту монтажа если указано
10. Болты затягивать динамометрическим ключом
